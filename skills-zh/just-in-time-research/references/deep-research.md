# 深度研究

当主上下文中的短调查不再够用时使用本文档。深度研究改变执行规模与拓扑；它不替代研究控制、状态、证据或搜索原则。

不要假定深度研究必须用多个代理或长报告。

## 仅在需要时升级

以下情况升级可能有用：

- 几条高影响支线可以独立调查；
- 一条支线需要很长的发现与验证链；
- 证据量无法再在活动上下文中可靠处理；
- 答案跨越多个系统、仓库、领域或文献体系；
- 重要来源相互冲突，需要独立调查；
- 错误的后果足以支撑更广或更深的验证；
- 用户显式要求广泛研究，且问题从中受益。

不要仅仅因为话题宽泛或难以解释就升级。

## 扩展到最小够用的系统

可能的形式包括：

```text
主 Agent 研究
→ 扩展的单 Agent 研究
→ 带外部化状态的单 Agent
→ 主 Agent 加一条委派支线
→ 若干并行支线
→ 多轮有界研究波次
```

独立缩放广度、深度、时长、外部状态、代理数量与并行度。更深的调查不一定需要更多代理；更多代理不保证研究更深。

## 按不确定性分解

委派研究问题，而不是报告章节。

一条有用的支线：

- 解决一个明确的不确定性；
- 对核心问题重要；
- 不需要完整轨迹就能理解；
- 有可识别的证据需求；
- 返回有界的结果；
- 与其他支线重叠最小。

避免"研究背景""调查一切""写安全章节""找更多信息"之类的模糊任务。

优先这样的支线：

```text
确定框架 X 能否在无应用托管检查点的情况下恢复被打断的工作流，并识别条件。
```

证据返回后，分解可能变化。

## 给出有界的简报

只提供执行支线所需的上下文：

- 精确问题；
- 为什么重要；
- 相关项目约束；
- 约束它的已确立发现；
- 要寻找的证据；
- 排除项或边界；
- 预期返回。

委派者应返回：主要发现、来源引用、支持与反驳的证据、范围条件、对核心问题的影响、剩余不确定性。不要索取它的完整轨迹或隐藏推理。

## 保持中央控制

主 Agent 拥有用户目标、核心问题、共享地图、暂定判断、支线间关系、冲突解决与最终综合。

委派者调查有界支线。它们可以报告父级框定有误，但不能默默替换目标或做无关的项目决策。

委派转移的是调查工作量，不是答案的责任。

## 把代理当上下文边界

委派应减轻主上下文压力。让委派者在隔离环境中检查大来源集或深入一条支线，只返回关键发现、条件、矛盾、来源位置、影响与未解决缺口。

不要把完整来源集或轨迹复制回主上下文。结果需要可恢复时使用 `research-state.md`。

## 并行化独立工作

当支线无需互相等待即可推进时并行：不同的技术、产品、文献体系、实现机制、利益相关者视角、或有意的独立验证。

当每一步依赖前一步的发现、支线需要持续共享状态、问题是一条因果或实现链、或协调成本超过收益时，使用顺序研究。

只有当独立验证或对抗性检查是有意为之的时候，才重复调查。

## 分有界波次工作

需要多个代理时，用波次而非不受控的递归扩张。

每轮波次之后：

1. 检查返回结果；
2. 去重；
3. 比较范围与假设；
4. 识别冲突；
5. 更新研究地图；
6. 修订暂定判断；
7. 决定是否还有理由再来一轮。

新一轮必须瞄准新识别的决策相关缺口，而不是仅仅延续活动。

## 限制递归委派

只有当支线包含真正独立的子支线、单一上下文无法可靠处理、能获得有意义的上下文或并行收益、仍可整合、且有界时，才允许递归委派。

不要递归委派模糊工作，也不要用委派逃避推理。

## 先整合再下结论

把委派结果当作输入而非最终答案。把承重发现追溯到证据，比较版本与假设，区分真正的共识与共享依赖，保留未解决的冲突，确定每条支线对项目的影响。

主 Agent 可能需要直接验证委派者的关键论断。

## 恢复与收缩

支线失败时，诊断问题是否过宽、上下文缺失、证据目标错误、获取失败、支线应拆分或合并、顺序工作更优、或支线已不再重要。不要原样重复同一请求。

问题变清晰后，降低并行度。当大多数支线已解决、只剩一条依赖调查、额外工作会重叠、需要本地实验、或综合比检索更有价值时，回到更小的形式。

最终综合通常应由一个 Agent 使用整合后的状态完成。

## 结束深度研究

当核心问题达到可决策状态、剩余支线不太可能改变答案、不确定性已有界、进展现在需要本地数据或实验、可信证据不可得、或预期研究价值不再值得成本时，结束扩张。

结果可以是明确答案、暂定判断、修订后的框定、实现提案、实验建议或未解决的分歧。不要默认输出长报告。

## 原则

```text
扩展研究，而非仪式。
用能解决重要不确定性的最少代理。
给每个代理一个有界问题和隔离的上下文。
把每个结果整合进一个共享理解。
只有当扩展可能改变答案时才扩展。
当综合比继续搜索更有价值时收缩。
```
